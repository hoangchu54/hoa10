3. Phương trình hóa học đang xảy ra

Tạo ↓AlCl₃ + 3NaOH → Al(OH)₃↓ + 3NaCl
Tan baseAl(OH)₃ + NaOH → Na[Al(OH)₄]
Tan acidAl(OH)₃ + 3HCl → AlCl₃ + 3H₂O
Tái tạo ↓Na[Al(OH)₄] + HCl → Al(OH)₃↓ + NaCl + H₂O
Ống 2MgCl₂ + 2NaOH → Mg(OH)₂↓ + 2NaCl
Tan acidMg(OH)₂ + 2HCl → MgCl₂ + 2H₂O

4. Nhận xét & Giải thích (SGK Hóa 10)

Hãy nhỏ dd NaOH 1M vào cả hai ống để so sánh trực tiếp: Al(OH)₃ tạo kết tủa keo trắng rồi tan hoàn toàn trong NaOH dư (hydroxide lưỡng tính), còn Mg(OH)₂ kết tủa trắng và không tan trong NaOH dư (hydroxide base).
